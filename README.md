# Global Lunar Rockfall Direction Analysis

This repository will host the code supporting the manuscript:

**A global vector field of lunar rockfalls reveals latitude-organized mass wasting**

The study investigates the global directional patterns of lunar rockfalls using LROC NAC imagery.

## Code availability

The code will be organized, documented, and uploaded to this repository after the manuscript is accepted for publication.

## Data

The lunar rockfall direction catalogue has been deposited in Zenodo:
https://doi.org/10.5281/zenodo.22805805
